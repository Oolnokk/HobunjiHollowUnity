Mapping
The Mao-ao source is a fixed 6×6 full-portrait grid: 36 points at 0%, 20%, 40%, 60%, 80%, and 100% on both axes. First, a recorded global transform applies independent X/Y scale about portrait center plus X/Y translation. Local node offsets are added afterward. Each of its twenty-five cells is treated as a bilinear quad, so all four corner nodes influence the entire cell. Each quad is internally subdivided for rendering, while the grid still reaches every portrait edge. Imported extended overlays support torso/base, torso clothing, and overwear only; arm sprites are deliberately left on the normal portrait plane.
