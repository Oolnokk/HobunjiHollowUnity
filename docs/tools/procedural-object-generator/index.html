Generate the game's existing procedural foliage/rocks from an exact seed + settings payload, then conservatively remove redundant planar triangles.

Object

The seed is passed through the same public builder path the game already uses. Saving and reloading the payload below reproduces the same generated object.

Settings

The reducer is deliberately conservative: the angle is the maximum difference between triangle face normals, measured in degrees. Connected patches must still pass the coplanar boundary checks; ridges, bends, raised centers, material groups, and morph geometry are left alone.
