⛓ Multi-sprite Weapons

Only weapons that declare a recipe use this renderer. The weapon key must match an existing TOOL_ITEM_DEFS entry or shape. Export the configuration to commit it for gameplay; local drafts are preview-only.

Rigid haft and chain

Both connector axes are relative to the final handle size: X changes chain width or generated rope radius; Y changes its length. The head retains an independent scale.

Pick on sprite opens the actual PNG at an independently fitted, tappable scale. For the Grapple-Flail head, choose “Between layers (composite)” to place a rope contact in the space between the two sprites. Picked coordinates are saved in original image pixels; no dependence on preview zoom.

Idle inertia and swing

Angular damping slows the released chain/head during Hold and Recovery. 0 = no drag; 8 = default (speed halves in about 0.09 s); higher values stop it sooner. Saved in the exported weapon recipe. The Attack Animation Editor previews your actual authored attacks.

Ordered sprite stack

Layers are drawn from back to front. The particle effect of each layer is inserted immediately after that layer and before the next; opaque artwork above it covers the particles.
