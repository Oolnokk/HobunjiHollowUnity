2D Beard ↔ Hood Negotiation

Paint beard cutout requests and hood-specific removal permissions. An allowed request removes hood cloth; a refused request removes the conflicting beard pixels and outlines the exposed beard edge. Tuft-root deformation and the original 2D layer order are preserved.

Repository artwork

Hoods tagged “hides facial hair” still hide the beard entirely, as on main. Use a regular hood to test the cutout.

Brush

At zero, every column directly below the detected bottom hood opening is removable. Increasing this widens the removable area like a cone; everything outside it rejects ordinary beard cutouts.

Manual allow/protect painting switches to a custom permission mask based on the current cone. Automatic uses the lower inner rim without painting. Green = removable, red = protected. Whiskers (purple) override both.

Only beard pixels at or above this alpha may be painted or marked as tuft corners. Erasing remains unrestricted.

Controls how far the ring moves toward a marked tuft. From 0 (none), quarter-pixel steps progressively stretch it; the ring reaches the marker once the amount is sufficient. No sudden cutoff.

Low subdivision spreads deformation broadly; high subdivision makes it more local. It controls the falloff area, not polygons.

Upper and lower sliders independently change how strongly surrounding cloth follows the tuft. The marked corner itself stays fixed at its target position.

In corner mode, tap the beard to place a tuft root, or drag a marker to move it. The nearest inner hood ring stretches to that root if it lies outside. The stretch limit prevents extreme warping.

Optional local art

Local PNG overrides affect only this editor's preview, not the cosmetic's authored game sprite paths.

Export

Beard export preserves existing fields and adds independent hoodWhiskerMask and hoodCutoutMask, hoodTuftRoots, and hoodTuftMaxStretch, hoodTuftSubdivision, and separate upper/lower influence values in the same shared or species-specific scope. The opacity floor is stored as editor authoring metadata. Hood export saves beardCutoutPermissionMode (auto, painted, or all), beardCutoutConeSpread, and optional manual beardCutoutAllowedMask. Missing policy defaults to the generated cone; painted permissions remain editable. Both exports preserve other cosmetic fields.

Paint on the beard or hood

Teal = ordinary beard request; purple = priority whiskers (hood loses); green = allowed cone/cloth; red = protected cloth. Yellow pixels mark detected bottom inner-ring points. Pink pins move the rim.
