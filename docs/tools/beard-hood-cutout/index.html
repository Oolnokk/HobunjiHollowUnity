2D Beard ↔ Hood Negotiation

Paint beard cutout requests and hood-specific removal permissions. An allowed request removes hood cloth; a refused request removes the conflicting beard pixels and outlines the exposed beard edge. Tuft-root deformation and the original 2D layer order are preserved.

Repository artwork

Hoods tagged “hides facial hair” still hide the beard entirely, as on main. Use a regular hood to test the cutout.

Brush

At zero, the allowed area extends straight down from the bottom opening. Widening opens the cone; the far-right Line setting makes its edge horizontal across the portrait. Everything outside still refuses ordinary cutouts.

The orange rim has separate upward and downward cones, each widening all the way to a horizontal line at the far right. The downward length limits how far protection reaches; the lower opening remains a hard stop. Both cones beat whiskers. No narrowing mode is introduced.

Manual allow/protect painting switches to a custom permission mask based on the lower cone. Green = removable, red = protected; purple whiskers override normal protection. **The orange upper cover is stronger than all three** and applies even with manual hood masks.

Both checks default to 95% opacity. Beard requests, whiskers, and tuft markers use the beard threshold. Hood allow/protect brush strokes and automatic ring detection use the hood threshold.

Controls how far the ring moves toward a marked tuft. From 0 (none), quarter-pixel steps progressively stretch it; the ring reaches the marker once the amount is sufficient. No sudden cutoff.

Low subdivision spreads deformation broadly; high subdivision makes it more local. It controls the falloff area, not polygons.

Upper and lower sliders independently change how strongly surrounding cloth follows the tuft. The marked corner itself stays fixed at its target position.

In corner mode, tap the beard to place a tuft root, or drag a marker to move it. The nearest inner hood ring stretches to that root if it lies outside. The stretch limit prevents extreme warping.

Optional local art

Local PNG overrides affect only this editor's preview, not the cosmetic's authored game sprite paths.

Export

Beard export preserves existing fields and adds independent hoodWhiskerMask and hoodCutoutMask, hoodTuftRoots, and hoodTuftMaxStretch, hoodTuftSubdivision, and separate upper/lower influence values in the same shared or species-specific scope. The opacity floor is stored as editor authoring metadata. Hood export saves beardCutoutPermissionMode (auto, painted, or all), beardCutoutConeSpread, optional beardCutoutTopConeSpread (downward widening), beardCutoutTopUpConeSpread (upward widening), beardCutoutTopDownConeLength (downward reach), and optional manual beardCutoutAllowedMask. Missing policy defaults to the generated cone; painted permissions remain editable. Both exports preserve other cosmetic fields.

Paint on the beard or hood

Teal = ordinary beard request; purple = whiskers (win against normal refusal); orange = upper-rim cover (beats whiskers); green = allowed bottom cone; red = protected cloth. Yellow dots = bottom rim, orange dots = top rim, pink pins = tuft deformation.
