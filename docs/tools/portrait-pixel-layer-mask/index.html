🧩 Portrait Pixel Layer Mask

Paint exact source pixels that should render at a different portrait stage without splitting the source PNG.

1. Source sprite

Uses config/cosmetics/index.json; clothing JSON and its selected portrait sprite are fetched directly from this build.
The mask must match the source dimensions. Painting outside opaque source art is harmless because runtime masking still intersects the sprite alpha.

2. Paint / move

Move mask drags the entire mask in whole source pixels. Arrow buttons nudge by 1 px. Ctrl/Cmd+Z and Ctrl/Cmd+Shift+Z also work.
