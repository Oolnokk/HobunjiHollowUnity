Avatarspecies / height
Swaps the preview body for a PNG plane avatar at that species' actual in-game height. The mesh is fitted to opaque avatar cells and its neck hinge is located from the base head sprite's alpha centroid. Neck strength scales the automatic body-yaw counter-turn; radius controls how softly the head weights blend into the torso. The vertex overlay marks every point with more than 1% head weight: cyan is a light blend and yellow is fully head-skinned. These are preview-only diagnostics and are not exported with the attack.
Combat statsdamage / range / hitbox
Loaded live from docs/config/combat/attack-values.json (falls back to a bundled default if the fetch fails, e.g. opened as a local file). The wedge shown in the viewport is the exact same 2D angle+range cone docs/game.js's inCone() tests hits against — height-agnostic, drawn flat at the rig's feet along its facing (+Z). Range is shown in tiles; entries that only have a rangeMul (no direct rangeTiles) approximate it against the base weapon's 'cut' range (2 tiles) purely for this preview.
