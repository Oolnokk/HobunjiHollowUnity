Geometry Workshop

Non-destructive remeshing and decimation of authored GLBs and generated meshes. Original materials and their triangle assignments stay intact.

1 · Source

Uses the real FoliageGenerator and ProceduralFurniture code, not a mock mesh.

Pick any visible authored or generated mesh from a linked game tab. Only Dev Mode permits picking. Tap here, switch to the game tab and tap the object, then return to the workshop.

Requires the game and workshop on the same website/origin.

2 · Geometry controls

Percentage of the mesh bounding-box diagonal. A smaller value adds more triangles to preserve curves. One bounded subdivision pass. Constrained edge collapses; material borders are locked. Actual reduction may be less than requested.

3 · Output

Load an object to compare geometry.

Export creates a new file; it does not replace a repository asset or change gameplay. Original GLB is never overwritten.
