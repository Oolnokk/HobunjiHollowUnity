Geometry Workshop

Non-destructive remeshing and decimation of authored GLBs and generated meshes. Original materials and their triangle assignments stay intact.

1 · Source

Uses the real FoliageGenerator and ProceduralFurniture code, not a mock mesh.

Pick any visible authored or generated mesh from a linked game tab. Only Dev Mode permits picking. Tap here, switch to the game tab and tap the object, then return to the workshop.

Requires the game and workshop on the same website/origin.

2 · Gameplay appearance

Reveals actual mesh topology. The edge overlay is for inspection only and is never exported. Turn this off to check whether dark seams or openings belong to the mesh or the outline renderer. Embedded GLB textures are retained. Game hand/foot surface materials affect only display clones, never exports. Loading the live game's shell shader and lighting definitions…

3 · Geometry controls

Percentage of the mesh bounding-box diagonal. A smaller value adds more triangles to preserve curves. One bounded subdivision pass. Constrained edge collapses; material borders are locked. Actual reduction may be less than requested.

4 · Output

Load an object to compare geometry.

Mesh integrity is checked when an asset loads. Edge-length cutoff will be measured from the source geometry. Actual subdivision work will be reported after Update preview. Rendered triangle counts will be verified after processing.

Gameplay quality JSON

For a procedural object, enter the path of its baked gameplay GLB. A generated-object profile only affects gameplay when that asset is loaded from this same path. Importing JSON does not automatically replace a live generator.
Export the matching optimized GLB too, then publish it to the expected assets/models/ path. In-game Settings → Performance → Geometry Detail can import one or more profile JSONs; tiers merge by source. Export creates a new file; it does not replace a repository asset or change gameplay. Original GLB is never overwritten.
