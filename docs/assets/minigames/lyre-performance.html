Controls and Rules

Locked input layout: development now uses 5 Banks · Auto Pick exclusively. Open, LT, LB, RT, and RB remain five ascending groups of four notes, while the left stick latches the automatic arpeggio or tremolo behavior.

Visual presets: Falling Strings preserves the existing twenty-lane presentation. 20-Note Timing Rings keeps every playable note visible at once in five widely separated four-note islands: LT upper-left, LB lower-left, Open center, RT upper-right, and RB lower-right. Inside every island, X/A/B/Y use the same left/bottom/right/top diamond as the face buttons. The Prompts dropdown chooses how many beats ahead solid timing rings appear; each ring contracts onto its fixed note circle, which lights and pulses during the playable window.

Hidden harmony: one shared transport drives the falling melody notes, visual/auditory metronome, automatic-pick grid, and chord changes. Free play uses the selected hidden progression. Public-domain songs replace it with their own silent chord timeline, which changes the notes chosen by arpeggios without adding backing audio. The optional root pad remains the only sustained harmony sound.

Automatic Pick: flick the left stick toward a direction to select a mode; it stays selected after the stick returns to center. The Auto Pick selector is a four-way cross; Up, Right, Down, and Left can each be assigned independently from the LS Slots library, including Single Note. The fast arpeggio uses a forward–reverse roll. Each new slow-arpeggio melody input alternates between a forward roll and a reverse roll. Every face-button press sounds its melody note immediately at the player's real tap time, then automatically fills every remaining subdivision before the next shared beat even if the button is released immediately. Base-rate mode therefore produces two total attacks when tapped within the first eighth-note slot of a beat; half-duration mode produces four, three, two, or one total attacks depending on how many sixteenth-note slots have already passed. Another musical input interrupts the remainder.

Fretted Pluck: select a left-stick picking direction, then press X, A, B, or Y as the melody note. Both arpeggio and tremolo attack immediately at the exact tap time and begin their beat-filling sequence without a hold-confirmation delay. Holding continues the same subdivision grid across later beats. Releasing finishes only the remaining slots before the next beat boundary. For arpeggio, the current four-string chord shape first replaces its nearest chord tone with the melody note when needed. Octaves are chosen only afterward: forward rolls rise compactly from the melody, reverse rolls fall compactly from it, and the fast forward–reverse roll rebuilds each half around the melody. Only the initial human tap is a gameplay input; every generated arpeggio or tremolo continuation is strictly auditory and cannot score, miss, increment the input counter, or flash a gameplay target.

Visual presets: Falling Strings keeps the original 20-lane display. 20-Note Timing Rings shows all twenty playable notes grouped into five face-button diamonds. Lyre View collapses the lanes down to four visible strings and moves the bank prompt into each falling note as an O / LT / LB / RT / RB glyph.

Successful Playthrough Preview: latch the left-stick mode you want to hear, choose a pattern, and press Preview Run. The normal gameplay view, prompts, metronome, chords, score, combo, and hit feedback remain active while the demo performs every required melody input perfectly. Its extra arpeggio or tremolo attacks use the selected left-stick mode but remain audio-only. Any real musical input interrupts the preview and returns control to you.

Keyboard fallback: A S D F mirror X/A/B/Y, and Q W E R mirror the shoulder controls where that layout uses them. In the hosted desktop layout, hold Shift and press an arrow key to select the matching Auto Pick direction. Number keys 1–4 remain an embedded fallback for Up, Right, Down, and Left. In Dual Arpeggio, U/O step the left wheel and I/K step the right wheel. In the original layouts U/O rotate the left arpeggio and I/K strum. Arrow Left/Right change the scale, and Esc pauses.

Sampler: import an audio file, set its actual root note, and every input pitch-shifts that same sample. Pedal sustain behaves like a piano with the sustain pedal held: releasing a control never cuts its voice, later notes layer over it, and repeated copies of the same pitch do not interrupt one another. Each voice rings naturally from Start to End. Pluck / retrigger keeps only the newest voice from the same physical control. “Clear Notes” fades all currently ringing sample voices.

Desktop controller: X/A/B/Y play the four notes in the active bank. LT, LB, RT, and RB select the four shifted banks, the left stick latches one of four cardinal Auto Pick modes, the right stick strums, Start pauses, and D-pad Left/Right select the previous/next scale. L3/R3 are unused.

Mobile audio: use Enable Audio once if the browser begins suspended. Imports are normalized, converted to phase-safe mono, and kept playable after returning from the mobile file picker.

MIDI Song Studio: import a Standard MIDI file, select its melody track/channel, choose how simultaneous notes collapse into one playable melody, and quantize or preserve its timing. The detector ranks possible tonic/scale combinations instead of hiding close alternatives. Time signatures now drive actual denominator-beat clicks, measure boundaries, count-ins, chord timing, prompt horizons, and automatic-pick subdivisions. Common signatures are presets; numerator, denominator, and accent grouping remain manually editable. Chords can be edited individually or batch-filled with a repeating Roman-numeral/scale-degree pattern over any measure range. Exported JSON can be reimported later or saved into the regular Pattern menu.

Recent change: Lyre View left arrows are now vivid green and right arrows are magenta, both with a much brighter glow. Their overflow beyond the clipped shoulder shapes, enlarged size, orientations, dimensions, note-circle sizing, and alignment remain unchanged.
