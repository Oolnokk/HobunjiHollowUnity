Subspecies identity

A subspecies is authored deliberately: duplicating an entry copies its item/glyph sprite, recolor and masks, minigame silhouette scale, behavior, ecology and price. Nothing here randomizes breeds.

Item / glyph artwork

The selected image from objectsprites is the fish's actual item artwork: it is used for the inventory glyph and for the item sprite shown when the fish is held. Recoloring and Sixfin mask layers apply to this image only.

Original raw sprite inspector

Minigame fish

The fishing minigame never uses the species/item artwork above. Every fish uses Hobunji's shared animated fish silhouette from assets/hud/fish_silhouette-body.png + whiskers. Subspecies differ visually in the minigame only by scale.

Fish item sprites

Choose the source image that becomes this fish's inventory/held sprite. The preview above shows the recolored/composited result, not the generic minigame silhouette.

Sixfin pattern masks

Masks are fetched from objectsprites/fish_patterns and composite over the item/glyph sprite. They are useful for Sixfin subspecies; masks authored to Sixfin may misalign on unrelated fish artwork.

Game-facing behavior

Fine behavior overrides — editor/test harness

The current game runtime uses class + difficulty. These extra knobs are exported separately so they can be integrated later without being mistaken for already-live fields.
